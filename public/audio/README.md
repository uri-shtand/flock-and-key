# Prototype audio assets

- `words/w001.mp3` … `words/w120.mp3`: prerecorded Hebrew synthetic speech prepared on 2026-11-10 using Google Translate's TTS endpoint (`translate.google.com/translate_tts`). The build-time preparation tool is `scripts/prepare-speech.py`; text is authored in `src/content/words.json`. It sends authored word/sentence text only, never progress or child input. These are prototype speech assets; no redistribution license from the provider is asserted here.
- Six original procedurally composed instrumental arrangements, revised for child playtest feedback on 2026-11-11 and generated by `scripts/prepare-music.py`. No samples or third-party music are used:
  - `farm-theme.wav` — 71.1 seconds, 108 BPM, marimba-led opening theme.
  - `meadow-walk.wav` — 80 seconds, 96 BPM, marimba melody with piano arpeggios.
  - `curious-trail.wav` — 87.3 seconds, 88 BPM, minor-colour pizzicato melody.
  - `letters-on-the-way.wav` — 73.8 seconds, 104 BPM, light piano melody.
  - `barn-rehearsal.wav` — 76.8 seconds, 100 BPM, bell melody and plucked accompaniment.
  - `evening-farm.wav` — 101.1 seconds, 76 BPM, soft flute-like melody without percussion.

Each arrangement has a 32-bar form: opening, fuller accompaniment, quieter bridge and return. The brighter tracks include a soft kick, brushed snare, shuffled hats and moving bass. Synthesis is deterministic and note tails wrap around the loop boundary. All tracks are mono 16-bit PCM at 22,050 Hz; peak levels avoid clipping. The track list is authored in `src/content/music.json`. These remain synthesized prototype instruments; the child's listening feedback is needed to judge their suitability.

All playback uses local static files. There is no browser speech synthesis, remote font, audio CDN or runtime AI request. The music ducks while speech plays. Speech files have been checked for presence and decoding; pronunciation and listening comfort still need a Hebrew-speaking human's review on the target computer.
