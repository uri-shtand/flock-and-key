# המשימות המשותפות של Flock & Key

רשימה חיה לניהול משותף. נוסיף כאן משימות ונעדכן מצב, החלטות ותוצאות בדיקה. `[ ]` פתוח, `[x]` הושלם; מזהי המשימות נשארים קבועים.

## פתוח

- [ ] **TASK-008 — לשחק בהרפתקת נוגה החדשה עם הילד.** לבדוק גילוי מחברת ותיק, שיחות, איסוף חפצים וחיבור שלושה רמזים בכל טבלה. להשוות רק תוויות גלויות לעומת תוויות במעבר עכבר. [תכנית ושאלות](noga-adventure-redesign.he.md).

- [ ] **TASK-003 — לחשוב מחדש על ״פיצי במרדף״ ו״עקבות בחשיכה״.** משוב: קלים מדי ולא מעניינים מספיק. הוסתרו זמנית מהבית ומהפרק, ללא מחיקת קוד או היסטוריה. לפני החזרה: להציע לכל משחקון אתגר ייחודי, להסביר למה הוא עשוי להיות כיף, להשוות למקורות ראשוניים ולבדוק עם הילד. להשוות שינוי אחד בכל פעם; לא להסתפק בהאצת הקלדה. החזרה דורשת החלטה משותפת.
- [ ] **TASK-005 — לבדוק עם הילד את הפתיח של נוגה.** האם ברור מי חסרה, למה מחפשים אותה ומה אפשר לעשות קודם? האם בדיחת פיצי עובדת? להשוות רק את הניסוח הישן לחדש, עם אותם רמזים ועזרה.
- [ ] **TASK-006 — לבחור את סבב השיפורים הבא יחד.** לרשום כאן תצפיות ממשחק אמיתי ולתעדף לפני הרחבת ההיקף.

## הושלם באיטרציה הנוכחית

- [x] **TASK-001 — ליצור רשימת משימות משותפת תחת docs.** זהו הקובץ.
- [x] **TASK-002 — להוסיף לפחות חמש אפשרויות הומוריסטיות ל״משנים את החווה״.** מגפיים לכבשים, עניבת פרפר לפיצי, משקפי שמש לשמש, כתר לברווז ודגל גזר. קנייה, הפעלה, הסרה ושמירה מקומיות; חנות בשני עמודים.
- [x] **TASK-004 — לשפר את פתיחת ״הטרמפ של נוגה״.** שיחת דמויות מאוירת בשימוש חוזר ברכיב הפתיחים, תעלומה קונקרטית ומשימה ברורה. אין שינוי בפתרון התיק.

תיעוד ההחלטות והבדיקות: [האיטרציה הנוכחית](iteration-farm-and-openings.he.md).

- [x] **TASK-007 — לעצב מחדש את נוגה כהרפתקת מפה.** מחברת רמזים ותיק חפצים מאוירים, שיחות ותצפיות, איסוף מפורש, שני לוחות פתרון עם גרירה וחלופת מקלדת, שמירה ודוחות.
