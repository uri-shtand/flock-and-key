# פלייטסט מועדון המילים החשאיות

## מעבר ראשון

`npm test -- tests/unit/wordDetectives.test.ts` נתן RED עם מודול חסר ו־GREEN ‏(1) אחרי הוספת כללי הביקור והגילוי. `npm run build` עבר. `npm run test:e2e -- wordDetectives` עבר (1) ב־Chromium. הסוכן בדק את הבמה, קרא שתי ראיות בקפה, מצא את הפנס והחזיר אותו. נשמרו `1024-initial-stage.png` ו־`1024-initial-found.png` תחת `output/playwright/vocabulary/word-detectives/`.

הגילוי צייר את הפנס, אבל לא את פתיחת לוח התצוגה או את האדם שהשתמש בו. בדיקת הבמה נתנה טקסט בלבד בלי מפגש חזותי מובחן עם התאורה החלופית. המודל השתמש באותו דגל לכל סוגי התמיכה, ולכן פתרון שנמצא במקרה לא אמר איזה פרט חסר. אין נתוני הנאה מילדים.

## שינוי ומעבר שני

בדיקת ראיות חסרות במועד הגילוי נתנה RED כשנמצא רק דגל תמיכה כללי, ו־GREEN ‏(2) אחרי שמירת המקורות החסרים. לוח התצוגה נפתח, עוזר המפות והפנס המאיר מופיעים ובבמה נדלקים זרקורים. נוסח התמיכה מציין כל מקור חסר בפני עצמו. פירוש השאלה ניתן גם במסלול המהיר, והחזרה מוסברת כשהפנס חוזר למדף. ה־GDD מתעד את גבולות העדות ואת דחיית משימת ההעברה.

`npm run test:e2e -- wordDetectives station` העביר את כל ארבע בדיקות התחנה. שלוש בדיקות המועדון נעצרו בהשוואת טקסט לא מדויקת של הכרזה. תוקנה בדיקת הטקסט והורץ `npm run test:e2e -- wordDetectives` מחדש (3 עברו). המעבר השני כלל את שני סדרי הביקור ומסלול ללא ראיות הקפה, בדיקת במה, תיקון כיוון, עזרה, Enter, מחברת, ריענון, החזרה ויציאה. נשמרו ונבדקו צילומים בשלושת גדלי היעד.

בפלייטסט אנושי: איזה פרט גרם לעבור מהבמה לשולחן? האם ילדים שמצאו במקרה יכולים לספר מה ההבדל בין רשות להחזיר בפועל? השוו את החקירה בסדר חופשי לאותה חקירה עם סדר ביקור מודרך.
