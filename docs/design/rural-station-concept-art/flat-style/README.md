# Flatter station production art

The source sheets below follow the [approved shop study](../station-shop-style-study.png). The game loads WebP derivatives for the scenes, portraits, stage actors and transparent shop props. The hall uses the left frame of the study. Its bench arm is a separate foreground crop above the cushion. The café and outdoor scenes keep the original layouts.

## ImageGen sources

All seven source files were made with built-in ImageGen using the approved shop study as a style reference. The family, cast, café and village sheets also used their corresponding earlier concept as the layout or identity reference. The Pitsi and rehearsal sprites used the earlier family lineup for identity. The game splits the transparent prop sheet into twelve independently placed objects and crops the dialogue portraits from the two cast sheets.
